Privacy policy

The Late Courier · last updated 11 October 2026

What this covers

The Late Courier is a YouTube channel. Its owner uses a private publishing tool (registered with Google as an OAuth app) to manage the channel's own YouTube account. The tool is not offered to anyone else, and no one else can sign in to it. This policy explains what that tool does with data from Google and YouTube, and what this website does with yours.

Data the tool accesses

With the channel owner's permission, granted through Google's sign-in, the tool uses the YouTube API Services to:

  • upload the channel's own videos, set their thumbnails and add their captions;
  • read YouTube Analytics and YouTube Reporting data for the channel's own videos (for example views, watch time, audience retention and thumbnail impressions), which YouTube provides in aggregate.

It does not access any other person's account, and it does not collect personal information about viewers.

How the data is used and stored

  • The data is used only to publish the channel's videos and to measure how they perform, so future episodes can be better.
  • It is stored on the channel owner's own computer and in the owner's private backup. Sign-in tokens are kept in the operating system's credential store.
  • It is not sold, rented or shared with anyone, not used for advertising, and not transferred to third parties.

The Late Courier's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google

The tool uses YouTube API Services. By using YouTube you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. Access granted to the tool can be revoked at any time on the Google security settings page.

This website

This site is static. It sets no cookies, runs no analytics or trackers and loads nothing from other sites. It is hosted on GitHub Pages, whose host may log basic request data such as IP addresses for security; see the GitHub Privacy Statement.

Retention and deletion

Analytics data is kept for as long as the channel uses it to improve its videos. Revoking the tool's access stops any further collection; stored data can be deleted on request.

Contact

Questions about this policy can be sent through the contact details on the channel's About page.

Changes

If this policy changes, the new version is published here with a new date.
